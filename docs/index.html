🐻 BeruangGuard

Screen an ERC-20 token approval on BNB Chain before you sign it. One unlimited approval to the wrong address can drain a wallet — this agent reads live on-chain data and gives you a deterministic verdict.

Try: bounded USDT approval · unlimited approval to an EOA · token with no code
    Full JSON response
    
  
    

  
    Every verdict is deterministic and reproducible from public chain data —
  re-run the same checks against the same chain state and you get the same verdict.
  BeruangGuard never asks for your private key and never signs anything.
  This demo runs entirely in your browser — it queries public BSC RPC endpoints
  directly. No server, no API key. BSC only (chainId 56) for now.
